## 0. Sequencing principle

**Evidence integrity first, then the trunk, then the renderer, then the design.**

The temptation is to build the new page and migrate content into it. That gets
the order wrong: the review found that the U.S. corpus exists in three
diverging copies (§4.1b–c), that three atlases publish an undocumented derived
value (§4.1a), and that nothing on the site can say when anything was true
(§4.2). A prettier renderer over that substrate would make the problems *less*
visible, not more — which is precisely the failure the brief names ("the site
should become a better representation of the evidence, not a prettier substitute
for it").

So: Phase 0 changes no pixels. Phase 1 changes no pixels. The design work starts
at Phase 3, on a substrate that can support it.

**No grand rewrite.** The current architecture — static HTML, hand-authored
GeoJSON, GitHub Pages — does not make incremental migration worse. It makes it
easy: each atlas is an independent directory, so atlases can convert one at a
time with the unconverted ones untouched and live. The one thing that *is*
effectively a rewrite — the page shell — gets rewritten once, as a template, and
then adopted nine times.

## 1. Disposition of what exists

### Preserve

| Thing | Why |
|---|---|
| The thesis and its cross-substrate discipline | The whole product |
| `control_layer` taxonomy (9 layers) | Survived 16 cases, extended once, deliberately. The conceptual spine |
| The dark semantic palette | Coherent; only its *mapping* is inconsistent |
| The overlay idea (consequence vs. control on one frame) | Best composition in the codebase; generalize it |
| `one_line` and the case prose | Genuine editorial voice. Do not regenerate, do not "tighten" |
| `confidence` + `confidence_note` | Right primitive, deploy it everywhere |
| `SYNTHESIS.md` | The authored argument. Becomes a first-class page, not a repo file |
| The handoff-to-specialists posture (§ trackdatacenters) | Rare and correct. Make it a page component |
| `REFRESH.md`'s primitives | The best existing spec for the build step |
| `maplibre-gl@4.1.2` | Works. Vendor it; do not chase 6.x |

### Retire

| Thing | Why |
|---|---|
| `docs/data/*.geojson` | Stale orphan, 15 vs 16 cases, superseded prose, publicly served, loaded by nothing |
| Filter toolbars (all 9) | Dashboard furniture over 5–16 authored cases |
| `card-stat` KPI pills on the splash | Count the schema, not the world |
| Hand-typed status strings ("Active crisis", "3 disrupted") | Status board with no backing signal; already removed once as "Live pills" (`986d79c`) |
| Inspector-panel-as-only-view | Cases get real URLs |
| `stress_band` choropleth as primary mark | Encodes magnitude as land area |
| Empty-state caveats | Boundary conditions move into the page |
| Eight duplicate copies of the shell CSS/JS | See Phase 1 |

### Generalize

- The overlay pattern → a `figure/map` variant available to every atlas.
- `confidence`/`confidence_note` → the register + standing system (grammar §2).
- `date_surfaced` (U.S. only) → an evidence window derived for every atlas.
- The `scope-note` line (cloud only) → the `boundary` component, everywhere.
- The trackdatacenters handoff (cloud only) → a `handoff` block, any atlas.

### Becomes shared library

`atlas-core/` — one place, consumed by all atlases and by the sibling repos:
tokens (color, type scale, spacing), the twelve primitives' CSS, the register
markers, the figure-footer contract, the receipts table, `map-figure.js`, and the
build/lint tooling.

### Stays site-specific

Which figure is primary; category vocabulary and hue assignment; mark type;
whether a map appears at all; the editorial voice; each atlas's derivation rules.

## 2. Phases

### Phase 0 — Evidence integrity *(no visual change)*

**0.1 Resolve the U.S. dual-source problem.** `REFRESH.md` names the decision
and defers it; 15 of 16 cases have now diverged, and the published copy is the
lossy one. **Recommendation: `cases/*.yaml` becomes the editorial source of
truth; `docs/us/data/cases.geojson` becomes generated.** YAML is the richer
copy, is diffable, is where a reviewer can work, and matches the sibling repo's
model. The reconciliation is a one-time human merge — for each of the 15 cases,
take the better sentence, note the drop (Texas Uri lost the KUT Radio source in
the GeoJSON), and record the merged result in YAML.

*This is editorial work and must not be automated.* A script may produce the
diff; a human ratifies each merge. Do not let the renderer project pick prose.

**0.2 Delete `docs/data/`.** Confirmed loaded by nothing.

**0.3 Write down the `stress_band` rules.** Three atlases, 30 features, one
undocumented derived value each. For each band atlas: state the inputs and the
threshold rule per band. If no rule was ever applied and the bands were assigned
by judgment, **say that** — `register: interpreted`, not `derived`. Either
answer is publishable; silence is not.

**0.4 Repair the 18 bare-domain citations.** Insurance (7/12) and subsea (9/18)
are the two that need work. Replace each with the specific document, or mark the
claim's standing honestly.

**0.5 Add `retrieved` and `archived` to the source record.** `retrieved` is
required going forward. `archived` for anything already 403/404-ing — the sample
found `wabe.org` dead and `docs.nrel.gov` unreachable at 25% coverage.

Phase 0 is the only phase with a hard ordering constraint: everything after it
assumes one source of truth per atlas.

### Phase 1 — Extract the trunk *(no visual change)*

Move the 129 identical CSS lines and 66 identical JS lines into
`docs/_atlas/atlas.css` + `docs/_atlas/atlas.js`; nine pages link them. Vendor
`maplibre-gl@4.1.2` locally (drops the unpkg-without-SRI dependency). Add
`.nojekyll` — now required, since `_atlas/` is underscore-prefixed.

Byte-for-byte identical rendering is the acceptance criterion. This exists so
that every later fix lands once instead of nine times.

### Phase 2 — Build step

Adopt `intake-composition-atlas/tools/` rather than inventing a second toolchain:
Python + PyYAML, `lint.py` refuses on error, `build.py` writes data and never
commits. Implement the `REFRESH.md` primitives that already have specs:
`count-derive`, `schema-check`, `drift-check`, `splash-generate`,
`readme-atlas-table`.

Add two:

- **`window-derive`** — `max(sources[].date)` per atlas. This is the honest
  freshness stamp `REFRESH.md` correctly declined to fake: fully derived from
  committed data, cannot drift, cannot overstate. It unblocks the deferred
  `freshness-render` without requiring a `last_reviewed` discipline the project
  does not have.
- **`register-check`** — every claim has a register; every `observed` has ≥1
  receipt and a denominator if it is a ratio; every `derived` has `inputs` and a
  `rule`; no `derived` carries a receipt.

Wire to CI (the repo has no `.github/` at all today) as a check, not a
committer — proposal-only, per `REFRESH.md`'s own doctrine constraint #3.

### Phase 3 — Case pages

Generate one static page per case, 85 total, from the same templates. This is
the largest single reader gain in the plan and it is mostly mechanical: every
case already has a title, a claim, prose, and sources. Case pages are
addressable, citable, crawlable, printable, and readable without JS — none of
which is true today.

Overview pages keep their current map for now and gain a `case-index` linking to
the new pages. Filters can come out here or at Phase 4.

### Phase 4 — First overview page migrated

The Hormuz specimen, §3 below. One page, full grammar, real material. Read it
before building the second.

### Phase 5 — Roll forward

Atlas by atlas, in order of how much the grammar buys:

1. **Hormuz** — specimen (§3)
2. **Insurance** — best quantitative material in the corpus (FAIR-plan 1.41M →
   395K), worst provenance (7/12 bare domains); chart-first
3. **Fertilizer** — third band atlas; benefits from the same fix as Hormuz
4. **Cloud, Subsea, Grid Equipment** — map is near-decorative; these become
   essay-plus-case-index pages and the map may not survive
5. **Water** — likely stays map-forward
6. **Chokepoints** — geography *is* the subject; map stays primary, gains
   annotation and a figure footer
7. **U.S.** — largest and most linked; migrate last, when the grammar is proven.
   Its overlay figure is the template for `figure/map` and should be lifted into
   the shared library at Phase 4, not rebuilt at Phase 7
8. **Splash** — rebuild against the `intake-composition-atlas` splash grammar
   (claim-headline, refusal block, register key, case list); retire the cards

Backport the shared library to `intake-composition-atlas` at the end — it gives
the grammar and receives the design system.

## 3. Specimen: `hormuz/` revised information architecture

### 3.1 Why this page

Not because it is the worst page — because it is the page where the gap between
**visual assertiveness and evidentiary support** is widest, which is exactly the
gap the grammar closes.

- Its dominant encoding, `stress_band`, is derived and undocumented (review §4.1a).
- It has the corpus's only genuinely quantitative dataset — `hormuz_oil_pct`,
  `hormuz_lng_pct`, `reserve_days`, `gen_fossil_pct` across 12 countries — so
  "charts as evidence" has real material.
- It already carries `confidence` + `confidence_note`, so the register system has
  something to attach to instead of being invented.
- The three brief categories map cleanly and visibly onto its existing fields:
  `reserve_days` is **observed**, `stress_band` is **derived**,
  `rationing_capacity` is **interpreted**. The page is a natural demonstration.
- Its newest source is **141 days old** while the page speaks in present tense.
  It is the strongest argument for the evidence window.
- It is one page and 12 features. Small enough to build twice if the first
  attempt is wrong.

### 3.2 What the current page hides

Sorting the dataset by `reserve_days` — which the map cannot do — surfaces
something the choropleth actively conceals:

```
country       band                      conf    oil%  lng%  reserve_days
Vietnam       acute_if_persists         medium   90    49     30
Philippines   already_stressed          high     92     —     45
India         price_shock_first         high     45    53     50
Thailand      acute_if_persists         high     80    28     95
South Korea   acute_if_persists         high     70    18    210
Singapore     resilient_but_expensive   high     70    45    245
Japan         price_shock_first         high     77     7    257
─────────────────────────────────────────────────────────────
Sri Lanka     already_stressed          medium   85     —      —
Bangladesh    already_stressed          medium   95    99      —
Pakistan      acute_if_persists         low      95    99      —
Taiwan        acute_if_persists         low      70     —      —
Cuba          special_case              medium    —     —      —
```

**Five of twelve countries have no reserve figure — and they include three of
the four most severe assignments.** Pakistan is banded `acute_if_persists` on
`confidence: low` with reserve data absent. Cuba is painted a color on the map
with *no observed inputs at all* — every quantitative field is null and the band
label is "Special case: distorted substrate," which is an interpretation, not a
measurement.

The choropleth renders all twelve identically. A reader cannot tell that the
bottom five are judgments and the top seven are calculations. **That is the
finding the new page should lead with**, and it required no new research — only
sorting the data the page already ships.

### 3.4 What the specimen tests about the grammar

1. **Does register survive contact with real data?** Cuba is the hard case —
   an entry with zero observed inputs. If the grammar forces it to render as
   `interpreted` with visible missing denominators, the register system works. If
   it needs a special case, the system is wrong.
2. **Does the 20s/3min/audit contract hold without contradiction?** The 20-second
   read is "three countries under sixty days, five unmeasured." The audit must
   confirm that, not walk it back. The current page's 20-second read is "twelve
   countries, five colors" — which the audit *does* walk back.
3. **Does demoting the map lose anything?** Hormuz is the strongest test: it is
   nominally a geography story, and the geography turns out to be one fact ("one
   strait") that a small locator carries better than a twelve-country choropleth.
4. **Does the evidence window change how the page reads?** Stamping
   `2026-03-26` on a page written in present tense, read in August, will feel
   uncomfortable. That discomfort is the correct signal and the page should not
   be softened to remove it.

Build it as a static spike against the real `countries.geojson`. The point is to
read it, not to ship it. If the grammar holds, promote its CSS into
`atlas-core/` at Phase 4.

### 3.5 Specimen as built — what changed against the sketch

`docs/specimen/hormuz/index.html`, generated by `tools/build_atlas_hormuz.py`
from `docs/hormuz/data/countries.geojson`. No new research, no rewritten case
prose, no JavaScript. Two departures from §3.3 worth recording:

**The Method section became a disclosure, not a threshold table.** §3.3 sketched
a rule statement with a fallback ("if no rule was ever applied, the section says
so"). The fallback is what happened. The section now opens: *"They were assigned
by judgment. No derivation rule was ever specified for `stress_band`, and none
can honestly be reconstructed."* It cites the commit, quotes that commit's own
framing ("stress bands, not countdown clocks"), and states explicitly that a
formula could be back-fitted to the twelve current values and was not. Every
band on the page renders `interpreted`.

**A third figure appeared, and it is the strongest thing on the page.** Building
the reserve chart surfaced a problem the sketch had not anticipated:
`reserve_days` is not one quantity. South Korea's 210 is strategic *oil* against
9 days of working LNG; Singapore's 245 includes storage it does not own;
Vietnam's 30 and India's 50 are midpoints of 20–45 and 25–74. **Five of the
seven published figures carry a recorded qualification — and every one of those
qualifications was already in the corpus, in the `confidence_note` field the
current map renders as a footnote.** The specimen adds a table that puts the
stored integer beside its own verbatim confidence note, with a mechanically
derived `qualified` flag (rule stated on the figure).

That is the test result. The grammar did not need new evidence to make the
atlas more honest; it needed a place to put the evidence that was already there.

## 4. What would make this plan wrong

- **If Phase 0.1's merge finds the GeoJSON prose is consistently *better* than
  the YAML**, invert the direction: YAML becomes generated and the editorial
  source moves to a per-case file derived from the GeoJSON. The decision is
  which copy an editor should work in; the measurement so far suggests YAML, but
  the merge itself is the test.
- **If `stress_band` turns out to have no rule and never did**, three atlases
  lose their primary encoding and become interpretation-forward pages. That is a
  legitimate and honest outcome, and it is a bigger editorial change than a
  redesign. Surface it before Phase 4, not during.
- **If the case-page count makes hand-curation untenable**, 85 generated pages
  with thin content is worse than 9 rich ones. Test with the 12 Hormuz country
  pages before generating all 85.

## 5. What is explicitly out of scope

Re-researching cases. Rewriting `one_line` or case prose to fit the layout.
Adding a framework. Adding interactivity. Adding atlases. Changing the thesis.
Chasing `maplibre-gl` versions. Any auto-commit of atlas content.

---

## 6. Immediate next step

Nothing in Phases 1–5 should start before **Phase 0.1** has a decision and
**Phase 0.3** has an answer, because both determine what the specimen is allowed
to say. Both are editorial calls, not implementation:

1. Which copy of the U.S. evidence is the source of truth?
2. Was `stress_band` ever computed from a rule, or assigned by judgment?

The second question in particular gates the specimen — it is the difference
between the Hormuz page having a Method section and having a confession.
